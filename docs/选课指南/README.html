    选课类型

    专选课（专业选修课）

    登录教务系统后，在"选课管理"→"方案课程"中查看本学期开设的专业选修课。

    体育选项课

    包括篮球、排球、足球、乒乓球、网球、匹克球、武术、拳击、跆拳道、街舞、体育舞蹈、轮滑、健身健美、体适能、羽毛球、攀岩与素质拓展等二十余种课程。

    校内公选课

    包括通识类、艺术类、体育类等各类选修课，大学四年需修够12学分。

    选课时间线

    专选课

    • 一轮选课：6月26日-28日
    • 二轮选课：6月29日-7月1日

    体育选项课

    • 选课时间：6月29日-7月1日

    校内公选课

    • 一轮选课：7月2日-4日
    • 退课时间：7月5日
    • 补选时间：7月6日-7日

    选课方式

    1. 教务系统网页版：登录教务系统进行选课
    2. 钉钉APP：通过钉钉扫码登录教务系统

    选课注意事项

    • 选课如同战争，特别多人抢，到时新生自然能领会到
    • 尔雅网络选修最多可以选6分，一学期最多3分
    • 选不到的课可以在补选阶段尝试
