    校园小贴士

    1. 新生报到：先对照本页地图熟悉校园环境
    2. 记住路线：教学楼、食堂、图书馆、快递站这几个高频地点先记熟
    3. 问路技巧：问保安、宿管、学长学姐都行
    4. 导航辅助：百度/高德地图在校园内也有一定参考价值
