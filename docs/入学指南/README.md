## 来校交通

由于学校在燕郊，而燕郊在北京周边，所以最方便的来校路线是先到达北京后，乘坐地铁公交到燕郊。

### 高铁/火车（最常用）

从北京各火车站下车后，换乘地铁到**大望路站**，再换乘**812路**公交到华北科技学院站（约45分钟）。

- **北京站**：2号线→崇文门→1号线→大望路→812路
- **北京西站**：9号线→军博→1号线→大望路→812路
- **北京南站**：4号线→西单→1号线→大望路→812路
- **北京丰台站** : 从北京丰台站地铁口进，乘坐10号线，坐五站，公主坟站内换乘一号线到大望路站，换乘812路专线或支线公共汽车，到华北科技学院站下车即到。

凭借录取通知书可购买优惠火车票（坐票半价，高铁动车75折）。

![alt text](/入学指南/来校交通.png)

### 自驾

根据宿舍所在区域导航到对应校区，大概率需要经过北京，需办进京证（北京交警App）。

## 报到流程

报到的具体流程：现场会有接待新生的工作人员来带着新生逐一完成。

### 报到需要带
- 录取通知书、钱、换洗衣物
- 各类材料、贫困生证明（需要的同学带）
- 常用药品、旧毛巾（打扫宿舍床铺）
- 1寸照片几张

### 注意事项
- 录取通知书中可能含有中国银行卡，务必保管好，大学四年的奖学金、助学金、学费书费缴纳都是通过这张卡
- 中行卡丢了先补办，三食堂西餐厅旁有营业厅
- 大学是有校服的，21届开始的是全蓝色，只有大一军训和学校重要仪式的时候穿

## 军训

军训的开始时间为报到3-5天后开始，军训时间两周左右。

### 军训内容
- 队型排列和动作
- 内务整理
- 紧急疏散
- 国防知识讲座

### 军训亮点
- 最后几天某天晚上会有迎新晚会
- 最后一天会举行阅兵
- 军训期间或军训结束会有百团大战（社团招新）

## 体育课

我校体育课种类繁多，包括：篮/排/足/乒/网/匹克各种球类、武术、拳击、跆拳道、街舞、体育舞蹈、轮滑、健身健美、体适能、羽毛球、攀岩与素质拓展以及其他共二十余种课程。

体育课是新生第一次通过教务网络管理系统选课。室外课会在大一下组织上三节游泳课，学校统一购买泳帽。
