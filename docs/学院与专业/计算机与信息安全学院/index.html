    学院简介

    计算机与信息安全学院围绕计算系统与信息安全，涵盖数据科学与大数据技术、网络空间安全、物联网工程、网络工程、软件工程、计算机科学与技术等领域，培养计算机与信息安全方向的高素质工程技术人才。

    学院对接数字化转型与网络安全需求，强化「计算 + 安全 + 应急」特色，为关键信息基础设施和应急信息化提供人才支撑。
