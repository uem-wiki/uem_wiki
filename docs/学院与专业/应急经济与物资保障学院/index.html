    面向应急经济、物资保障与工商管理的经管类学院。

    学院简介

    应急经济与物资保障学院围绕应急经济管理与应急物资保障，涵盖金融学、电子商务、市场营销、工商管理、供应链管理、国际经济与贸易、会计学等领域，培养应急经济与物资保障方向的高素质管理人才。

    学院对接应急产业发展与应急物资保障需求，强化「经济 + 管理 + 应急」特色，为应急物资供应链与企业经营管理提供人才支撑。
