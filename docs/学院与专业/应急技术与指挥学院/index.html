    应急技术与指挥学院

    应急管理 应急技术与管理 智慧应急 应用心理学

    应急管理大学最具应急特色的核心学院之一。

    学院简介

    应急技术与指挥学院是应急管理大学"应急"办学底色的集中体现，聚焦应急管理、应急技术与管理、智慧应急、应急心理等方向，培养能够在政府应急管理部门、企事业单位、应急救援机构从事应急管理、应急指挥、灾害处置、应急心理服务等工作的高素质应用型人才。

    学院是全国首个「智慧应急」本科专业的所在地（2025 年获批，国家控制布点专业）。

    ⚠️ 学院详细沿革、师资规模、实验室、教学成果等信息待补充（需从学院官网 yjxy.uem.ncist.edu.cn 获取，该站限校内访问）。

    学院亮点

    • 🏆 全国首个「智慧应急」本科专业所在地
    • 🎯 对标国家应急管理人才需求，突出"应急 + 指挥"实战能力
    • 🔗 融合应急管理部行业资源与实战训练
