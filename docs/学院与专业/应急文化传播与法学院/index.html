    面向应急文化传播、新闻、法学与汉语国际教育的文法学院。

    学院简介

    应急文化传播与法学院围绕应急文化传播与法治建设，涵盖广告学、网络与新媒体、新闻学、汉语国际教育、法学、汉语言文学等领域，培养应急文化传播与法治方向的高素质人才。

    学院对接应急舆论引导与法治建设需求，强化「传播 + 法律 + 应急」特色，为应急科普宣传、舆论引导与依法应急提供人才支撑。
