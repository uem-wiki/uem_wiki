    化工安全学院

    化工安全工程 化学工程与工艺 材料科学与工程 应用化学

    聚焦化工安全、化学工程与材料、应用化学的工科学院。

    学院简介

    化工安全学院面向石油化工、危化品安全领域，涵盖化工安全工程、化学工程与工艺、材料科学与工程、应用化学等专业，培养化工与危化品安全方向的高素质工程技术人才。

    学院对接危险化学品安全治理与化工产业高质量发展需求，强化「化工 + 安全」特色，为危化品生产、储存、运输安全提供人才支撑。
