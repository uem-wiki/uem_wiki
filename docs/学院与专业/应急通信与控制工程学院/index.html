    应急通信与控制工程学院

    信息工程 测控技术与仪器 人工智能 通信工程 电子信息工程 自动化

    面向应急通信、控制工程、人工智能与电子信息工科学院。

    学院简介

    应急通信与控制工程学院围绕应急通信与智能控制，涵盖信息工程、测控技术与仪器、人工智能、通信工程、电子信息工程、自动化等领域，培养应急通信与控制方向的高素质工程技术人才。

    学院对接应急通信保障与智能制造需求，强化「通信 + 控制 + 智能」融合，为应急通信网与智能装备控制提供人才支撑。
