    矿山安全学院

    安全生产监管 采矿工程 矿物加工工程

    聚焦矿山安全生产、采矿工程与矿物加工的特色学院。

    学院简介

    矿山安全学院是应急管理大学面向能源与矿产资源安全领域设立的特色学院，围绕矿山安全生产、灾害防治、矿产资源高效利用等方向开展人才培养与科学研究，服务国家矿山安全监察与煤炭行业高质量发展需求。

    学院依托学校长期积淀的安全工程与采矿工程学科基础，强化「安全 + 矿业」融合特色，培养能够在矿山生产企业、安全监察监管机构、科研院所从事矿山安全生产技术、灾害治理、资源开发等工作的高素质应用型人才。
