    应急装备学院

    产品设计 机械电子工程 材料成型及控制工程 机械设计制造及其自动化 电气工程及其自动化 应急装备技术与工程

    面向应急装备设计与制造、机电与电气工程的工科学院。

    学院简介

    应急装备学院（应急设计中心）围绕应急装备研发设计制造，涵盖产品设计、机械电子工程、材料成型及控制工程、机械设计制造及其自动化、电气工程及其自动化、应急装备技术与工程等领域，培养应急装备方向的高素质工程技术与设计人才。

    学院对接国家应急装备产业需求，强化「设计 + 制造 + 应急」融合，为应急装备研发、生产、保障提供人才支撑。
